| 碱基 | 取的残基 | 原子数 |

## 3. 真正的缺陷：四个锚点目标退化

`aform_from_template.py:122-142` 把 C1'/C4'/O3' 的**目标位置**硬编码出来，
再用这组目标做四点 Kabsch，把 1EHZ 残基贴上去。实测（61 残基，以 `b = P[i]->P[i+1]` 为轴分解）：

| 量 | 1EHZ 实测 | 代码目标 |
|---|---:|---:|
| C1' 沿轴 / 垂直 / 距离 | 3.25 / **4.16** / 5.33 | 5.50 / **1.50** / 5.70 |
| C4' 沿轴 / 垂直 / 距离 | 2.79 / **2.63** / 3.90 ± 0.04 | 4.20 / **0.00** / 4.20 |
| O3' 沿轴 / 垂直 / 距离 | 4.85 / **1.68** / 5.22 | 4.19 / **0.00** / 4.19 |
| **\|C4'-O3'\|** | **2.44 ± 0.04** | **0.01** |

两条：

1. **四个锚点全被放在主链轴上**（垂直分量一律 0）。真实的三个锚点都不在轴上。
2. **C4' 与 O3' 被放到同一点。** 目标里 `c4_dst = P[i] + 4.2 b`，
   `o3_dst = P[i+1] - 1.6 b`；对 A-form 螺旋 `\|P[i+1]-P[i]\| ≈ 5.79`，
   所以两者都在 `P[i] + ≈4.2 b` —— 差 0.01 Å。真实距离是 2.44 ± 0.04 Å
   （C4'–C3'–O3' 两个键，几乎刚性）。

**后果**：四点拟合的目标四面体退化，绕主链轴的转动**无定义**。实测后果：

- 每个原子相对 P 的向量在模版里与在重构后的夹角：**均值 ≈ 86–90°，标准差 ≈ 38–43°**，
  在三种 P 轨迹（平面环 / A-form 螺旋 / 螺旋加噪声）上一致 —— 即一个**任意滚转角**。
- 拟合残差（拟合后原子到它该命中的目标）：P 均值 1.07、**最大 21.8 Å**；C1' 1.36 / 18.3；C4' 1.48 / 19.8。
- Kabsch 是刚体变换，所以残基**内部**几何被完整保留（模版 `\|C1'-P\|` 5.27，重构后仍 5.27）。
  **误差纯粹是取向的。**

## 4. 修法分两层

**第一层：把目标四面体做成立体且形状正确。** 用上面那张表的实测值取代硬编码。
只要 C4' 和 O3' 不再重合、垂直分量不再为零，拟合的三个转动自由度就都被约束住，
任意滚转消失。这一层是纯数据修正。

**第二层：垂直方向 `r̂` 的定义。** 目前 `r = P[i] - centroid`（全局，从分子质心朝外），
这就是"所有碱基都向外辐射"的原因。要做对，`r̂` 必须来自**局部**化学：
候选是配对伙伴方向（Level 0 已有 BPP 分层），或局部螺旋轴。
这一层才是科学问题。
