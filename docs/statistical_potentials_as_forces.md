## 2. 四条要点

### 2.1 "注入"这个说法要改

我们的 CG 力场（IsRNAcirc 血统）本来就是统计参数化的。所以不是"把外来的统计势注射进物理力场"，
而是"**在一个统计势场上再加一层统计项**"。这不是措辞问题 —— 它决定会不会**双重计数**：
知识型势本质上是自由能（PMF）的一类，里面已经隐含着物理相互作用。

### 2.2 失败的原因是分辨率错配，文献里有原话

cgRNASP 原文：

> 现有的传统统计势（RAPDF、KB、DFIRE-RNA 等）**全都基于全原子表示**。因此，**至今各个不同
> CG 层级上仍然急需可靠的 CG 统计势**。

同文另一句（点名了整条路线）：

> 几乎所有现有的物理模型都基于不同层级的 CG 表示，而不是全原子 —— 包括 SimRNA、iFold、NAST、
> IsRNA、Vfold、HiRe-RNA、oxRNA、RACER 和我们带盐效应的 CG 模型。

所以 TriRNASP 失败的病根不是"统计势不能进力场"，而是**拿全原子的统计去配 CG 的场**。
我们记的"量级差 ~50 倍、极小值不一致"正是这个错配的症状。

### 2.3 解法有两条，我们上次两条都没走

| 路线 | 代表 | 做法 |
| :-- | :-- | :-- |
| **同层级计数** | cgRNASP / cgRNASP-CN | 直接在 CG 表示上统计，不改力场 |
| **迭代再加项** | IsRNA2+（iterative reweighting）；IsRNA（iterative simulated reference state）| 反复调整势，直到模拟出的统计量复现目标统计量 |

我们上次是**一次性硬塞一个固定系数**（`trirnasp_scale = 0.002`）。
那既不是同层级计数，也不是迭代标定 —— 所以受挫是预期的。

### 2.4 进力就需要梯度

打分函数只要能量值；进力场要解析梯度。可微的统计势是有的（Bernauer et al.），
但我们没有核过原文，也没有确认它在 CG 层级上的形式是否可直接用。

## 3. 重写后的三个问题

1. **在哪一级计数？—— 开关已经查清：我们的 3 珠是名义上的，不是真的。**

   cgRNASP 的 3 珠是 **P / C4' / N9(嘌呤) 或 N1(嘧啶)**，都是真实重原子。我们的不是：

   | 位置 | 珠子怎么来的 |
   |---|---|
   | `torch_gpu_refine.py:132-133` | `pos_c4 = pos_p + bb_dir*0.034`；`pos_n = pos_p + bb_dir*(-0.015)` —— **沿骨架方向的偏移** |
   | `openmm_gpu_refiner.py:224-225` | `p + rng.normal(0, 0.3, 3)` —— **随机扰动**，注释写 “corrected later by minimize” |
   | `openmm_gpu_refiner.py:233-235` | 索引定义 `P(i)=3i, C4(i)=3i+1, N(i)=3i+2` |
   | `aform_from_template.py:52-53` | 全原子重构用的是**另一组**三锚点：**P / C1' / C4'** |

   两条后果：

   - **cgRNASP 的统计不能直接搬。** 珠子数一样（3）、名字一样（P/C4'/N），
     但 N 不是糖苷氮，C4' 也不一定是真 C4'。同名不同物。
   - 更要紧的一条：`torch_gpu_refine.py` 里 C4' 和 N **都与 P–P 方向共线**，
     所以这两颗珠子只编码局部主链切向，不携带任何垂直于主链的信息，**也就没有序列信息**。
     在它们上面加统计势，等于给“P 坐标 + 切向”再加一层统计 —— 增量可能很小。

   **出路**：`aform_from_template.py` 的 1EHZ 重构本来就会给出每个残基的**真实**全原子几何。
   从那里读出真正的 C4' 与 N9/N1，就得到一个货真价实的 CG 表示，可以在上面按 cgRNASP 的方式统计。
   **这件事必须先做**，否则后面所有关于统计势的讨论都是在装饰珠子上做文章。
2. **怎么加才不打架？** 走迭代（IsRNA2+ / IsRNA 路线），而不是固定系数。剩下两件没人替我们做：
   把 cgRNASP 的统计转成**可微**形式（它原本是打分用的距离依赖势，不是力），以及定标。
3. **加成，还是重参数化？** 底层场已经是统计的，所以"再加一层"和"重新拟合"是两条不同的路。

### 3b. cgRNASP 的实际计数方案（2026-09-10 补读正文）

原文（NAR Genom Bioinform 2023;5(1):lqad016，PMC9985339）：

- **距离 bin 宽 0.3 Å**（不是 1 Å）。
- **残基间距 k₀ = 5** 为界：长程 k ≥ 5，短程 k ∈ {1}、{2}、{3–4} 分档处理。
- 各 k 档的**距离截断值不同**，按该档内 CG 珠子的实际距离分布定。
- 长程项带一个**与链长 N 有关的归一化 f(N)**，权重 ω = ω₀ / f(N)。
- **参考态用 finite-ideal-gas**，不是 rsRNASP 的 random-walk-chain（原文说前者表现更好且被广泛使用）。

### 3c. 可行性计数的结论

在一棵真实的三珠表示上（1EHZ，76 残基），我按 1 Å bin 数了 14,633 个珠子对距离：

| 通道组 | 距离数 | 通道 | 格子 | 占用 | 中位数 |
|--:|--:|--:|--:|--:|--:|
| 骨架–骨架 | 11,400 | 3 | 270 | 25.9% | 55 |
| 骨架–碱基 | 11,400 | 8 | 720 | 9.3% | 62 |
| **碱基–碱基** | 2,850 | 10 | 900 | **7.3%** | 12 |

只取短程档（cgRNASP 说它比 rsRNASP 更细致的那一块）：

| 通道组 | 占用 | 中位数 |
|--:|--:|--:|
| 骨架–骨架 | 21.1% | 9 |
| 骨架–碱基 | 7.5% | 4 |
| **碱基–碱基** | **5.3%** | **1** |

**携带序列信息的那一组，93% 的格子是空的，中位数 1 个计数。**

而且这已经是**宽松的一侧** —— cgRNASP 用 0.3 Å bin，格子还要多三倍。

两个结论：
1. **计数不够。** 一条 76 残基的 tRNA 撑不起同层级的势。
2. **多样性也不够，而且这条更硬。** 一条结构只给一个折叠的统计。拿相似结构去堆计数，
   喂的是参考态，不是势。cgRNASP 用 191 条非冗余结构，出处是公开的。

**所以第 1 步的答案是：能做，但必须先取数据。** 数据在

### 3e. 读法

1. **数据门槛是实测出来的，不是估的**：191 条结构 / 12,299 残基 / 270 万计数 → 63.5% 占用。
   这就是「能用」的成本。
2. **短程是结构性稀疏，不是偶然。** 类 1 只有 2,448 个格子，而要填它的是分离恰为 1 的珠子对 ——
   无论多少条结构，这个数都只是残基数的常数倍。**更长的链不解决它，更不一样的折叠才解决。**
   这正是计划书 §1b 那条「长度 × 相似度双层分层」要挡的东西。
3. **长程档反而宽裕**（82.9%），因为它是 O(N²) 累积的。
4. **对我们的直接含义**：cgRNASP 的珠子是**按碱基分型的 12 类**（连 P 和 C4' 都带碱基标签），
   而我们力场里的 C4' / N 是 p + bb_dir*offset 造出来的、**不带碱基类型、且与主链共线**。两边对不上。
   **出路是现成的**：aform_from_template.reconstruct_all_atom 的输出里本来就有模板给的
   真实 C4' 与 N9/N1。把力场的珠子定义换成它们，cgRNASP 这套就**直接兼容** ——
   不需要重新发明计数方案。
   （已实施，见第 3f 节。）

### 3g. 现在能注入了吗——不能，卡在梯度（2026-09-10）

把已备好的与还缺的列清：

| 需要的东西 | 状态 |
|---|---|
| 真珠子 (P, C4', N9 或 N1) | ✅ `real_cg_beads()`，已接入两条 torch 路径 |
| cgRNASP 的完整方案 | ✅ k / Rc / intervals / 12 类型 / 能量合成，全部已知 |
| 训练数据 | ✅ 191 条天然结构在 D:\torusfold-cgdata\ |
| **力场认不认珠子类型** | ❌ `cg_energy_forces` 用的是裸索引 `P(i)/C4(i)/N(i)`，**没有碱基类型**，读不了 12×12 的表 |
| 我们自己的势表 | ❌ 还没数 |
| 读表求值的代码 | ❌ 没有 |
| **梯度** | ❌ **根本问题，见下** |

**梯度为什么是根本问题**

C 实现是查表：`potential[i][j][(int)(distance/0.3)]`。表本身是**段内恒定**的：

| 文件 | bins | 相邻 bin 完全相等的比例 |
|---|---|---|
| 0-1（分离=1） | 17 | **79.0%** |
| 1-2（分离=2） | 30 | 52.9% |
| 2-4（分离=3–4） | 43 | 47.4% |
| long（分离≥5） | 80 | 15.6% |

也就是说：**最短程那一档、79% 的区间上势能是常数** ⇒ -dE/dr 恒为 0；其余的导数集中在 bin 边界，
是个 δ。直接拿它当力，积分器在 79% 的地方不受力、在边界上受到无限大的力。

当年 TriRNASP 那次必然出问题：**没有插值，直接对阶跃函数做 CPU 前向差分**。
步长小于 bin 宽得到 0，大于得到粗斜率 —— 那 38% 的方向错误就是这么来的。

**三条出路**

1. **把表插值**（线性或样条）→ 得到分段线性势，导数良定义。改动小，但会轻微改变势本身。
   这是最便宜的一条。
2. **不查表**：直接用核密度估计重算 E = -kBT·ln[P_obs(r)/P_ref(r)]，梯度可解析。
   即所谓「可微统计势」路线（Bernauer et al.，仍未核原文）。更贵，但干净。
3. **只当打分函数**（领域惯例，也是 NOTES.md 当年收敛到的结论）。

**结论**：珠子这一步已经通了；**要注入，下一步必须先造一个可微表示** ——
已做，见第 3h 节。
### 3h. 可微表示：做出来了，而且验证通过（2026-09-10）

`scripts/test_cg_potential_differentiability.py`。同一组珠子上，两种表示对照：

| | 能量 (kBT) | 解析梯度 vs 中心差分 (h = 1e-4 Å) |
|---|---|---|
| binned（C 代码原样：`int(r/0.3)` 查表） | -79.2155 | **36/36 个分量精确为 0**，max \|FD\| = 0 |
| **线性插值（bin 中心之间）** | -78.6411 | **36/36 通过**，最差 \|FD − 解析\| = **9.4e-10** |

能量差 **+0.57 kBT（0.7%）**。也就是说：**把表线性插值，就得到一个自洽的可微表示，
而势本身只变不到 1%。**

实现要点（两处我一开始写错了，记下来）：

1. **超出每档截断的距离必须跳过，不能外推。** C 代码是 `if((int)(r/0.3) < intervals)`，
   越过就丢。我第一版在表外插值，插值版的能量差了一个数量级。
2. **`1/fun(N)` 要同时作用在能量和梯度上。** 只除能量不除力，自洽性检验必然不过。
3. 两端取平（斜率 0），否则第一/最后一格会外推。

**这一步之后，注入的障碍清单变成：**

| 需要的东西 | 状态 |
|---|---|
| 真珠子 (P, C4', N9/N1) | ✅ |
| 可微表示 | ✅ 本节，已验证 |
| cgRNASP 全部参数 | ✅ |
| 训练数据 | ✅ |
| **知道 12 种珠子类型的力场代码路径** | ❌ 还没有 |
| 我们自己的势表 | ❌ 还没数（现在可以直接用他们的表做测试） |
| **定标与双重计数** | ❌ 概念问题，见下 |

**双重计数这一条仍然悬着。** cgRNASP 的势是 -kBT·ln(P_obs/P_ref)，本质是自由能；
而我们的 CG 力场本身也是统计参数化的。再加一层统计项，加的是已经隐含在里面的东西。
这跟可微性无关，是**加什么**的问题，不是**怎么加**的问题。


### 3i. 注入之后的松弛实验：方向对，但结论不能用（补测）

`scripts/relax_with_and_without_cgrnasp.py`。起点是 `real_cg_beads` 从 1EHZ 晶体 P 轨迹重建的珠子，
用阻尼梯度下降走 400 步（中位步长 0.005 Å，单珠位移上限 0.05 Å），指标是 P-superpose 后的珠子 RMSD。

| 组合 | all | P | C4' | N | E_cgrnasp (kBT) |
|---|---|---|---|---|---|
| 起点（我们的重建） | 1.241 | 0.480 | 1.230 | 2.014 | — |
| CG only | 1.977 | 1.892 | 1.255 | 2.785 | −39.96 |
| CG + 0.1 cgRNASP | 1.918 | 1.812 | 1.224 | 2.718 | −188.45 |
| CG + 0.5 cgRNASP | 1.713 | 1.456 | 1.194 | 2.490 | −674.19 |
| CG + 2.0 cgRNASP | 1.480 | 1.073 | 1.172 | 2.196 | −854.43 |
| cgRNASP only | **1.193** | 0.463 | 1.153 | 1.963 | −792.37 |

（早先一版没传 cell list，clash 项被静默跳过；那版里珠子转碱基朝向能量一模一样，作废。这里全程传了。）

**打乱对照。** 能说明"改善来自信息量"的唯一对照是把序列信息毁掉：几何、配对表、表值、插值器、
步长标定全部不动，只随机置换"哪个残基拿到哪种碱基类型"。平滑性与力的量级分布因此都保留。

| 组合 | real | null 均值 ± sd (n=12) | p |
|---|---|---|---|
| cgRNASP only | 1.193 | 1.215 ± 0.010 | 0.077 |
| CG + 2.0 cgRNASP | 1.480 | 1.530 ± 0.019 | 0.077 |

**p = 0.077。** 12 个零信息对照没有一个比真表更接近晶体，但均值只差 0.022 Å。
按纪律，p > 0.05 不能写"提供了增益"。总改善是 1.241 → 1.193，共 0.048 Å，其中 0.026 Å
来自零信息对照 —— **这份改善里一大半是势的笼统形状（平滑、压缩），不是它记住的距离依赖。**

**更要紧的是，这个实验测的不是精度。** 起点的 P 直接取自晶体 P 轨迹，P 偏差 0.480 Å
已经贴着重建自身的上界 0.444 Å（§9）——**起点的 P 本来就是对的**。于是：

- CG only 把一条误差 0.48 Å 的 P 轨迹推到 1.892 Å；
- cgRNASP only 把它留在 0.463 Å。

这读作"谁的力更温柔"，不是"谁更准"。起点已经正确，任何移动都让 P 变差，
所以这个指标天然偏向"什么都不做"的势。

**起点处的中位力：CG 200.0 kJ/mol/nm（= 20 kJ/mol/Å），cgRNASP 166.8 kJ/mol/Å。**
（早先这里写"CG 2,000.0 kJ/mol/Å，差 12 倍"，是我自己的单位错误：`cg_energy_forces` 返回
kJ/mol/nm，1 nm = 10 Å，换算应当**除以** 10，我乘了。正确的数是 CG **小** 8 倍。
真正的问题不是大小，而是 200.0 **正好是上限值本身** —— 见 §3j。）

**训练集关系（必须说明）。** 1EHZ **不在** cgRNASP 的 191 个训练结构里（该目录 192 个文件，
无 1ehz）。但 `1FIR.pdb` 在里面，61 nt，也是 tRNA —— 与 1EHZ 同一个折叠。
所以这不是自包含，是**折叠熟悉**：势见过这个折叠。§1b 那条相似度分层正是为挡住这个而设的，
这里没做，结果偏乐观。

**结论：**
1. 松弛实验不能用来判断 cgRNASP 项是否有用（p = 0.077，且指标偏向不动）。
2. 目前唯一有信息量的证据仍是诱饵排序（native 排第一，7/7），但那是单结构 n=7。
3. **我们自己的 CG 力场在近天然几何上把结构推坏** —— 这比"要不要注入"更该先解决。

**要定这件事需要的是**：多个结构、与 cgRNASP 训练集不同源（或显式分为"折叠熟悉/折叠新颖"两层）、
留一法、诱饵排序，加打乱对照。不是再调松弛步长。

### 3k. 重定标的实测：方向修好了，量级没修（补测）

`scripts/recalibrate_ff_targets.py`。**珠子直接从 rsRNASP 训练集的沉积坐标取**（P / C4' / N9-N1），

设计：32 个结构，**前 16 个拟合常数，后 16 个留出测试** —— 所有报告的数字都在留出集上。
每个结构配 6 个高斯扰动的诱饵（σ = 0.3 / 0.6 / 1.0 Å，各 2 个），能量走 `cg_energy_forces`。

常数不是手填的，是从拟合集**重新导出**的：对 `0.5*k*(q-q0)²` 形式的限制项，最优 q0 是观测量的**均值**；
对约束 cos 的项，是观测**余弦**的均值，不是平均角的余弦。

| 设置 | 中位 \|F\| | 在帽上 | native rank | 最好的诱饵比 native 低 |
|---|---|---|---|---|
| A 原样（STACK_R0 0.505，DIH 180°） | 187.5 | 1396/2541 | **6.94 / 7** | **13264.8 kJ/mol** |

**第一条结论，也是这一节最重的一条：按出厂常数，这个力场认为天然结构比它自己的随机扰动还差。**
native 在 7 个候选里平均排 6.94，最好的诱饵比它低 13,264.8 kJ/mol。这不是"力大"，是**符号错了** ——
力场的最小值不在天然结构上。上一节那两个常数错得离谱，正是原因。

**第二条：只重定标这两个常数，排序就修好了。** 6.94 → 2.00，margin 13,264.8 → 363.0。
留出集上成立，不是拟合出来的。

### 3l. 现成方案：文献里的做法，以及我们该走哪条（讨论）

**先说我上一节的错。** §3k 里我把目标设成观测量的**均值**，理由是"均值最小化均方误差"。那个推导对，
但目标错了 —— 均值只在分布对称时才是一个"分子真会待的地方"。伪二面角的分布是重度偏斜的，
`scripts/check_bonded_distributions.py` 一看就清楚：

| 坐标 | 力场目标 | 均值 | **众数** | 落在众数 |
|---|---|---|---|---|
| P-P-P-P cos | −1.000 | +0.608 | **+0.975** | 35.0% |
| P-P-P cos | −0.866 | −0.740 | **−0.875** | 22.9% |
| P(i)-P(i+2) nm | 0.505 | 1.110 | **1.125** | 29.8% |

**众数才是力场该定到的地方**：它是分子实际所处的状态，而均值可能落在两个状态之间。
逐结构的众数更硬（243 条链）：**240 条自己的伪二面角众数在 cos > +0.8，只有 1 条低于 −0.8**；
235 条 P-P-P 众数低于 −0.8；**0 条** i,i+2 距离众数低于 0.7 nm。

带符号看（`scripts/check_signed_pseudotorsion.py`，n = 10631）：**均值 −12.90°，中位 −16.62°**，
56.1% 落在 0° 的 ±30° 内，只有 5.1% 落在 180° 附近，74.6% 为负。
也就是说 P-P-P-P 伪二面角实际在 **−20° 附近（近顺式）**，力场写的是 180°（反式）—— 偏了将近 180°。
用众数重跑（`recalibrate_ff_targets.py`，16 拟合 / 16 留出）：

| 设置 | 中位 \|F\| | 在帽上 | native rank | margin |
|---|---|---|---|---|
| A 原样 | 187.5 | 1396/2541 | **6.94** | −13264.8 |
| B 众数 | 127.6 | 1191/2541 | **1.44** | −210.1 |
| B' 均值 | 139.2 | 1204/2541 | 1.88 | −346.5 |
| C 众数 + angle | 129.0 | 1195/2541 | **1.12** | −35.5 |

**B 与 C 的差别只有 0.009 的目标余弦，margin 却从 −210 变到 −35。这个敏感度不正常**，
n = 16 下 1.44 与 1.12 分不开。只有"A 是灾难性的"这一条在噪声之外。

**文献里现成的方案：有，而且只有一种，方法是标准的。**

1. **Boltzmann inversion（玻尔兹曼反演）** —— 键合项的标准做法，`U(q) = -kBT ln P(q)`，
   P 从结构数据库统计得到。**迭代版 IBI** 在 MD 与反演之间来回迭代，修正项与项之间的关联。
   文献：Li W, Chen S-J，*Building RNA Coarse-Grained Force Fields: Design Principles and Training
   Strategies*，Biophys J 2026，doi:10.1016/j.bpj.2026.03.041（PMC13110076，PMID 41877485）。
   该文的训练方法小节标题就是 "Boltzmann Inversion of reference probability distributions" 与
   "Iterative Boltzmann Inversion (IBI)"。
2. **该文对"做天然结构预测的模型"的判据，和我们正在做的测试是同一件事**：SimRNA / IsRNA2 / RNAJP
   "often adopt training strategies to reproduce detailed statistical distributions of structural
   parameters. Validation of such models is achieved primarily by their ability to search for and
   identify native conformation." —— 我们用 native vs 诱饵的排序来验证，正是这个标准。
3. **有一份公开数据集的先例**：*Dataset of normalized probability distributions of virtual bond
   lengths, bond angles, and dihedral angles for the coarse-grained single-stranded DNA structures*

### 3n. 路 2 的配方（从综述抄下来的，含两个正式名字）

Li & Chen 那篇综述（Biophys J 2026, PMC13110076）的 Table 1 把 CG 参数化方法列成一张表。
和我们相关的两条，都属于 bottom-up：

**DBI —— Direct Boltzmann Inversion。**
`U(q) = -kBT ln P_ref(q)`，P_ref 是参考分布。
优点："Straightforward in concept and implementation."
缺点："**Does not account for correlations between different degrees of freedom.**"

**IBI —— Iterative Boltzmann Inversion。**
在 MD 与反演之间迭代，`U_{i+1}(q) = U_i(q) + kBT ln(P_i(q) / P_ref(q))`。
优点："Can account for correlations between different degrees of freedom."
缺点："**Convergence not always guaranteed.**"

**IsRNA 用的是改良 IBI**，这一点值得抄：它不从全部参数一起优化，而是**分批加**。先只有键长和
体积排斥（LJ），假设键长互相独立；其余参数在后续迭代里逐步加入。原文：

> the individual potential terms extracted by the IsRNA procedure depend on the order they are
> added to the training process. ... However, **the sums of the energy terms in the final force
> fields are not sensitive to the iteration orders.**

也就是说，**一项一项加是有授权的，先加键长不会把后面的搞坏。**

**整条 §3 线的理论落点，综述里有原话：**

> In DBI and IBI methods, it is common practice to use experimental structural distributions as
> references. Potentials obtained in this manner are sometimes referred to as **'statistical
> potentials'**. ... One way of thinking about the statistical potentials is to treat them as
> scoring functions, reflecting the preferred values adopted by different degrees of freedom in
> the native configurations of RNA molecules.

拿实验天然分布建的 CG 势，本来就叫统计势。§3 起于"怎么把统计势注入力"，绕了一圈，
**这就是标准做法本身。**

**我们的检验也有名字。** Top-down 那半边有一条 **Energy Funnel Optimization**：
"Requires energy landscape to adopt funnel shape" / "The energy landscape should guide folding
toward native state" / "**Requires the generation of a well-designed set of decoy structures**"。
就是 native vs 诱饵排序。而 §3i 那种松弛对应 **RMSD Minimization**，综述给的缺点原话是
"lacks analytical gradient, and requires the use of less efficient numerical derivatives" ——
和我们测到的 p = 0.077 是同一件事。

**所以：我们的计划是标准计划，我们的检验是标准检验，而 §3k 测出的那个失败**
（力场把天然排在 6.75/7）**正是 Energy Funnel Optimization 存在的理由。**

**路 2 的具体步骤：**

1. 对每个键合坐标（P-P 键、P-C4'、C4'-N、P-P-P 角、P-P-P-P 伪二面角、P(i)-P(i+2) 距离），
   从训练集统计 `P_ref(q)`。
2. `U(q) = -kBT ln P_ref(q)`，制表，用与 §3h 同一套 bin 网格。
3. 用**已经验证过的**可微制表求值器算能量与力（bin 中心线性插值 + 解析梯度，
   与中心差分吻合到 9e-10）。不需要写新代码。
4. **尾巴要加墙。** `-ln P` 在采样范围之外没有定义，插值会把它拉平 —— 也就是"自由"，
   坐标可以无代价地跑到分布之外。综述没谈这一条，这是我自己要处理的地方：
   需要在 `P_ref` 的支撑边界外接一个上升的墙，否则同样的塌陷会以另一种形式回来。
5. 重跑留出集上的 Energy Funnel 检验（`scripts/recalibrate_ff_targets.py` 的框架，
   换成制表势）。
6. DBI 的已知弱点是不管自由度之间的关联，而键合项确实互相关联 ——
   **所以大概率要走 IBI**。IBI 需要 MD 在环里，是个大得多的循环。
   综述也说了 "Convergence not always guaranteed"，所以先 DBI 看差多少，再决定。

**先做 1–3，用 DBI，跑第 5 步。** 如果 DBI 的分布复现不了参考分布，再谈 IBI。

（≤ 0.3 时 gap 精确为 0；到 30 倍也只有 −2.5 kJ/mol），而调和项是 1.250 / −41.2。

**所以：**
- **形状是对的，标度是漏斗看不见的。** §3o 那个 1.00 不是"更软的势更好"—— 同一个形状从
  0.03 倍到 30 倍都能拿 1.000，而任何倍数的调和项都拿不到。差别在形状。
- **标度不能用漏斗定，必须换一个机制。**
- **不能把"曲率配平"当答案**（第 2 条已经排除）。

**结论：保持 DBI 的字面标度（倍数为 1，表就是平均力势），把标度交给 IBI。**
理由：（a）没有任何测量支持乘一个系数；（b）没有任何可用的检验能挑出系数；
（c）**IBI 恰恰就是干这件事的** —— 它迭代到模拟出来的分布复现参考分布为止，
而"复现参考分布"本身就同时定住了形状和标度。

**这一步把 IBI 从"可能要做"变成了"必须要做"**：它是目前唯一一个能用证据定标度的机制。

### 3r. 我给的机制是错的；而且修不了这个病（补测）

**§3q 里我写的"梯度正比于 `k|cos φ - c|/(b sin φ)`，在 φ→0 与 φ→180 处发散"是错的。**

重推链式法则：`dE/dx = k(cos φ - c)·(-sin φ)·dφ/dx`，而 `dφ/dx` 的量级是 `1/(|b| sin θ)`，
**θ 是键角不是二面角**。所以 `sin φ` 在**分子**上、会消掉，发散点在**键共线**，不在二面角平面。

实测（`scripts/diagnose_dihedral_large_force.py`，411 个窗口）：

| 量 | 与 \|F\| 的相关 |
|---|---|
| 1/sin(二面角) | **0.082** |
| 1/sin(θ1) | 0.198 |
| \|cos φ\| | −0.182 |

**没有任何几何量单独解释得了它**。而 §3q 说的"把目标从 180° 挪到 12.8° 所以进了奇异区"，
按重推的结果不成立 —— 两个目标都不在奇异点上。

**结论：你批准的那个方案（把约束写在该角 φ 上而不是余弦上）修不了这个病。**
两种形式共用同一个 `dφ/dx`，而发散在那个因子里。**它没做。**

**顺带查出一个确定的缺陷，已修。** `boltzmann_bonded._chain_residues` 只保留 A/C/G/U，
中间的修饰核苷酸被丢掉，于是列表里前后两项在链上可能隔了好几个残基，
却被当成一根骨架键、一个角、三个二面角用。实测 **7354 对相邻项里 93 对（1.26%）是这种间隙**，
步长 2 到 10。**而那正是玻尔兹曼表的分布来源。**

修法是在编号不连续处把链断开。修完验证（`scripts/verify_gap_fix_and_dihedral.py`，60 条链）：
P-P 步长 3061 个，**超过 0.90 nm 的 0 个**，均值 **0.591 ± 0.047 nm** —— 干净的天然带。

**然后是我统计量用错的更正。** 我引用过"二面角中位力 2323.7，是帽子的 11 倍"。
那个数是**逐窗口取四原子最大值、再取中位**，不是逐珠子的中位力。逐珠子的中位是 **3.60**。
两者不是一回事，我混用了。

### 3u. 非键合项能不能承重：能，而且配对项是唯一的承重者

§3t 把折叠全压到了非键合项上，而它们一次都没验过。高斯诱饵测不了这件事 ——
它会把键拉断、造出碰撞，所以任何惩罚局部几何的项都会抓到它，而配对项根本没被考到。

**换成长度自配对的诱饵（`scripts/test_nonbonded_fold_signal.py`）：同一个结构、同一批残基、
同一份几何，只把"谁和谁配"随机重排。几何一点没变，所以每一个键合项按构造都对差异免疫。**
如果依赖配对的项仍然把正确的那份排在更低，它们就带着折叠信息。

**而 FULL 的 +38,213 与 wc pair + bpp 的 +38,251 基本相等，GB/SA 贡献约 0。**

**结论一：配对项承重，而且承得住。** wc pair **24/24**、bpp **23/24**、总数 23/24。

**结论二：能量账本证实了 §3t 的判断。** dihedral 是**单项最大的能量项**（6,946，超过净能量），
angle 1,908，bsj closure 2,638 —— 而三个局部项加起来才 34。
**占着能量预算的两项做的是零折叠功。**

**三条保留：**

1. **诱饵太粗。** 随机重配对会让配对的伙伴隔得很远，配对能量被拉爆是**必然**的
   —— 和 §3k 的高斯诱饵是同一个毛病。24/24 说明的是"这些项对配对敏感、方向对"，
   **不是**"能把正确折叠从似是而非的错折叠里挑出来"。要问后者得用**近天然诱饵**
   （配准位移 register shift），那是下一个测试。
2. **一列标签曾经是错的。** 我先前把 `mean|delta| / mean|total|` 写成"占总能量比"，
   那是敏感度不是占比。已改成两列：真正的 `mean |E|` 和它相对净能量的比例。
   超过 100% 是因为总数是带符号的和、有大量抵消，它读作"该项能量量级相对净能量"。
3. **stacking 在这张表里是 0.0**，因为它是 P(i)-P(i+2) 距离项，而重配对不改几何。
   它是否承重，这个测试答不了 —— 要改几何才考得到它。
