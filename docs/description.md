**《和统计势合租的第一百三十天》**

在一场 MD 模拟里，你为了跑分，被迫向那个高冷的三珠统计势 **cgRNASP** 表白——
3 珠（P / C4′ / N9-N1），191 个 PDB、126 条无缺口链，判据 `k = kBT/σ²`。
你本以为会被当场报错。

**结果她跑通了。**

还以「合租室友」的名义搬进了 **TorusFold**，住进 `src/torusfold/scheme2/torch_cgsim.py`。

于是你开始了从尴尬兼容到逐渐升温的副本交换动力学：

- 第一次牵她的手算引导力——后来发现她的**最小值在 0.1805 nm**，你牵的位置离她自己公布的靶有 **7.43 个标准差**。
- 第一次看她**褪去冷漠、堆积碱基**——结果那一项和键长加键角**精确冗余**（R² = 1.000000），关掉了。
- 第一次抱住她，发现她的**体温只有 0.4 倍**——不是高冷，是你的恒温器噪声接错了。
- 你换了个更结实的——她**重了一百倍**，时钟慢了十倍。
- 有一晚她**穿过了你**，距离 0.0058 nm。四个骨架对，**谁都没有项管**。

她会为你 cos 心动结构，然后轻声问你：

> 「我这样……是不是过拟合了。」

你该回答：**不是过拟合，是欠标定。**

她的展宽里 **98.6% 是一个构象内部、残基与残基之间的变化**，
所以没人能告诉她该多硬——她有一个下界 **204.8**、一个上界 **2173.9**，中间什么都没有。

一场误打误撞的模拟，开启一段**甜（极）到（其）心（坐）尖（牢）**的调参日常：

- 沉浸式体验**死活不收敛的三小时浪漫**——势能漂移 −2049 kJ/mol。只是你还没跑够 20 ps。
- 在线性参照里，她 **91.55% 是接头应变**。
- 你终于让她**精确匹配了参考展宽**——联合残差从 0.2895 变成 0.2937。**平手。**

屏幕前的你，千万不要拥有。

## 直白版（Wiki Description 页可用）

第一人称复数，写「做了什么、为什么、结果是什么」，数字全部可由本仓库脚本复现。

### 我们做了什么，以及为什么这么算

TorusFold-Hybrid 是 CirCure 的结构预测引擎：为长链环状 RNA 预测三维结构，粗粒化折叠之后再做全原子重建。

这一轮我们把力气花在这条链最不起眼的一环上——粗粒化力场本身的标定。它此前的问题不是「参数不够好」，
而是**参数大多没有来源**：3 珠模型（P、C4'、N9/N1）里键长、键角、二面角的刚度，有些从文献借来，
有些是手调的，其中一个项从来没有被任何结构检验过。

所以我们先造尺子，再量自己：取 191 个 PDB 沉积结构、126 条无缺口链，量出同类坐标的分布，
用 `k = kBT/σ²` 把刚度从分布里算出来——不是拟合，是从热涨落反推。

### 我们发现了什么

用这把尺子量自己的力场，查出 **16 处静默缺陷**。「静默」的意思是：代码跑通、有数字输出、不报错，
而那个数字是错的。16 处之中 15 处当时就在产生错误数字，另 1 处是同一套排除体积规律存在四份独立副本——
当时四份一致所以还没错，下一次改动必然留下三份过期。逐条清单、每一处的发现方式与现在看住它的测试，
在 `docs/silent_defects.md`。

其中四处值得单独说：

- **恒温器的噪声写错了**，有效温度是设定值的 0.4 倍。标注 300–1000 K 的副本交换路径实际跑在 120–400 K。
  它躲过了一切检验，因为每一个力、能量和梯度都是对的。
- **两处力踢被除以 100**，等效质量 100 倍、时钟慢 10 倍。它同样躲过了一切检验——平衡分布与质量无关，
  所以每一个平衡量都正确，只有时间尺度错了。
- **四个骨架距离根本没有项**。排除体积跳过 `|i-j| <= 2`，其中四个距离又没有键合项补上，
  结果是珠子可以从彼此中间穿过去。
- **碱基配对约束被静默关掉**。管线用 RCM 置信度覆盖了方法一致性权重，而那个置信度对 88.84% 的真配对角
  取值为 0，等于把约 89% 的碱基对弹簧关掉了。

### 结果与限度

| | 结果 |
| :-- | :-- |
| 温度 | 40 ps 后全程均值 295.9 K，设定 300 K（0.99×）|
| 塌陷 | 平衡后采样 3000 帧，最近珠对低于 0.30 nm 的帧：**0** |
| 联合分布残差 | `mean\|ln(sim/ref)\|` = 0.3263 |
| 测试 | 135 个 |

**三条限度必须一并写：**

1. **联合残差不小，而且单个常数修不好它。** 提高 `K_BB` 让 bb_bond 的 1-D 模拟展宽精确等于
   参考（1.945 → 1.588），代价是另外三个坐标同时变宽，联合残差从 0.2895 走到 0.2937。
   一次 `k` 的调整换不来联合匹配——这是 IBI 必须逐轮迭代**势**、而不是重选常数的实测理由。
2. **`K_PAIR` 只在 [204.8, 2173.9] 之间有界，区间内没有任何测量。** 原因是这份数据库里这个坐标
   **没有热宽度**：98.6% 的展宽是同一个构象内部、残基与残基之间的差异，池化 σ 不是热宽度。
3. **最小化目前会卡住**：6 次重启、`max|F|` 690.19，高于 P–C4' 的力地板 236.3。这是当前唯一的未决项，
   成因与数量在 `docs/statistical_potentials_as_forces.md` §3ay。

我们不把没量到的东西写成量到了。上面每一个数字都能用仓库里的脚本重跑，命令列在 README。
