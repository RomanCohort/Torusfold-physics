**《和统计势合租的第一百三十天》**

在一场 MD 模拟里，你为了跑分，被迫向那个高冷的三珠统计势 **cgRNASP** 表白——
3 珠（P / C4′ / N9-N1），191 个 PDB、126 条无缺口链，判据 `k = kBT/σ²`。
你本以为会被当场报错。

**结果她跑通了。**

还以「合租室友」的名义搬进了 **TorusFold**，住进 `src/torusfold/scheme2/torch_cgsim.py`。

于是你开始了从尴尬兼容到逐渐升温的副本交换动力学：

- 第一次牵她的手算引导力——后来发现她的**最小值在 0.1805 nm**，你牵的位置离她自己公布的靶有 **7.43 个标准差**。
- 第一次看她**褪去冷漠、堆积碱基**——结果那一项和键长加键角**精确冗余**（R² = 1.000000），关掉了。
- 第一次抱住她，发现她的**体温只有 0.4 倍**——不是高冷，是你的恒温器噪声接错了。
- 你换了个更结实的——她**重了一百倍**，时钟慢了十倍。
- 有一晚她**穿过了你**，距离 0.0058 nm。四个骨架对，**谁都没有项管**。

她会为你 cos 心动结构，然后轻声问你：

> 「我这样……是不是过拟合了。」

你该回答：**不是过拟合，是欠标定。**

她的展宽里 **98.6% 是一个构象内部、残基与残基之间的变化**，
所以没人能告诉她该多硬——她有一个下界 **204.8**、一个上界 **2173.9**，中间什么都没有。

一场误打误撞的模拟，开启一段**甜（极）到（其）心（坐）尖（牢）**的调参日常：

- 沉浸式体验**死活不收敛的三小时浪漫**——势能漂移 −2049 kJ/mol。只是你还没跑够 20 ps。
- 在线性参照里，她 **91.55% 是接头应变**。
- 你终于让她**精确匹配了参考展宽**——联合残差从 0.2895 变成 0.2937。**平手。**

屏幕前的你，千万不要拥有。

**TorusFold。力场重标定、九处静默缺陷、131 个测试、一个还没迭代的 IBI。**
