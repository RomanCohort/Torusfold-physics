# `dihedral` 换查表：决定所需的事实

这份文档记录一件具体的事：**把 `dihedral` 从「cos 上的单井谐振子」换成「表格 Boltzmann 势」这个决定，需要先知道什么。**

它不提出结论，只把这一周量出来的事实按「支持 / 阻碍 / 未决」摆清楚，并写明**什么测量能让它变得可决定**。

所有数字都来自 `results/` 里的日志，每个都指得到 `scripts/` 里的脚本。

---

## 一、为什么要换：单井形式在任何 k 下都不成立

**参考分布是双峰的。** 从 `results/boltzmann_tables_clean.npz` 的 `dihedral__U` 反出 `P∝exp(−U/kBT)`（kBT = 2.494 kJ/mol）：

| 特征 | 位置 q=cosφ | 质量 | 深度 |
| :-- | --: | --: | --: |
| cis 盆地（q ≥ 0.8） | 峰在 +0.9967 | 63.2% | 0 |
| **针尖**（q ∈ [0.9876, 1.0]） | | **15.6%（1011 个观测）** | 0 |
| **trans 峰**（q < −0.80） | −0.9967（φ≈175.3°） | **6.5%** | **2.25 kBT** |
| 中间宽尾（|q| < 0.8） | | **30.3%** | — |

整体 mean 0.5954、**σ 0.5920**、skew −1.60。（`scripts/reference_shape_modes.py` → `results/reference_shape_modes.log`）

> **阈值要写死，否则数字对不上。** trans 的质量随阈值变：`q < −0.80` → 6.53%、`q < −0.90` → 4.70%、`q < −0.95` → 3.53%。文献里见到的「6.5%」用的是 −0.80、「4.6%」用的是 −0.90，**两个都对**。

> **一条表的硬限制**：最上一格的区间是 **`[0.9876, 1.0049]`——它跨过 `q=1`**。所以表**在物理上分不开 `q=0.99` 和 `q=1.0`**，而那 15.6% 的质量全在这一格里。（用 bin 中心去问「`q > 0.9967` 占多少」会得到 0.02%，那不是数据，是格点分辨率的假象。）

**`σ_ref = 0.592` 是混合量**：cis 峰内 σ 只有 0.054、trans 0.058——0.592 几乎全部来自 cis↔trans 的分离和那 30% 中间尾巴，**不是任何单井的热宽度**。

**判据（三项同时评）**：`scripts/reference_shape_modes.log` 的叠加表

| | 出厂 k=7.2 | 测度校正 k=2.371 | 参考 |
| :-- | --: | --: | --: |
| σ | 0.3507 | **0.5880** | 0.5920 |
| skew | **−1.47** | −0.84 | −1.60 |
| trans 峰 | 无 | 无 | 2.25 kBT |

**没有 k 同时满足——而且两个 k 都产不出 trans 峰。**「改常数」这条路到此为止。

**这不是 dihedral 独有的形式问题，是判据层面的。** `k = kBT/σ²` 只对**测度平坦**的坐标成立：

| 坐标 | 测度 | 测度正确的 1-D / ref |
| :-- | :-- | --: |
| bb_bond / intra_pc / intra_cn | 距离（r²dr 修正亚百分级） | **0.997 / 0.999 / 0.999** |
| angle | 键角（平-cos 正确，但 cos∈[−1,1] 截断） | **0.688** |
| dihedral | torsion（平-φ，投影 Jacobian 在 q=±1 发散） | **0.596** |

（`scripts/measure_all_coords_1d.py` → `results/measure_all_coords_1d.log`）

**三条距离坐标不受影响，两条 cos 坐标中招。**

## 二、trans 峰是真的，不是数据库污染

`scripts/dihedral_tail_provenance.py` → `results/dihedral_tail_provenance.log`，逐结构归因：

| 组 | 观测数 | 覆盖结构数 | Herfindahl | 1/N | top-5 占比 |
| :-- | --: | --: | --: | --: | --: |
| 中间尾巴 | 1927 (30.2%) | 122 | 0.0114 | 0.0082 | 9.9% |
| trans 峰 | 296 (4.6%) | 100 | 0.0138 | 0.0100 | 12.5% |
| cis 盆地（对照） | 4050 (63.4%) | 126 | 0.0102 | 0.0079 | 8.5% |

**三组 H 都 ≈ 1/N、top-5 都只占 ~10% → 均匀散布在 100–122 条链里。** 所以是**真的构象异质性，不是少数异常结构**，**不能靠洗参考消掉**。

## 三、形式：第一轮的「参数化全部不过」是拟合方法的产物，不是形式的

> **这一节的结论被推翻了两次，写清楚过程。**

**第一轮（错）**：`scripts/dihedral_nonharmonic_fit.py` 用**极大似然**拟合 Fourier 与高斯混合，两者都退化（系数撞 ±200 界，σ→0），于是结论是「参数化形式都表达不了『尖 cis 峰 + 浅 trans 井 + 平坦宽尾』三件事」。

**推翻它的原因**：改**加权最小二乘**（权重 = 参考 bin 质量）之后，**Fourier N=2 完全可用**——σ 0.590（参考 0.5916）、skew −1.585（−1.599）、trans 深度 2.22 kBT（2.25）。**而 N=2 就是收敛点**（N≥3 只在小数第三位抖），这一点有物理理由：`cosφ` 与 `cos2φ` 两项**本身就是双井**。

**「精确解析形式」确实不能当力用**（这一条保留）：要让平-φ 采样产出参考分布，势必须是 `V(φ) = U_ref(cos φ) − kBT·ln(sin φ)`，第二项是**测度/熵项**，`dV/dq = kBT·q/(1−q²)` 在 `q→±1` **发散**——而 cis 和 trans 两个峰正坐在那里。实测 `dV/dq`：

| q | dV/dq |
| --: | --: |
| 0.99670 | 1427 |
| 0.99900 | 2296 |
| **0.99990** | **13519** |
| 0.99999 | 125749 |

**但这条对有限阶 Fourier 反而成了优势**：Fourier 没有那堵熵墙，所以 `dV/dq` 天然有界。**它分布拟合得稍差，正是因为缺了那一项。**

## 三之二、力的参考实现（唯一一份）

`scripts/force_reference.py` → `results/force_reference.log`。签名固定：

```
dihedral_force(spec, pos, ij_like=None) -> (E:(B,), F:(B,N,3))
```

`spec` 覆盖 `shipped_harmonic` / `table` / `("table_jac",None|eps)` / `("fourier",K)`；能量与力来自**同一个** autograd 图（无事后加项、无 detach）。

**已核验**：它的 `table` spec 与 `boltzmann_bonded.mixed_energy(which=["dihedral"])` 在 2OIU 上**能量差 0.5%、力差 1e-12**。

**为什么需要它**：在此之前有**四份互相矛盾的「力」**（16477 / 7111 / 519 / 519），因为它们各自用了不同的样本、分格与求导路径。**其中一个 519 后来被查出是脚本里一个几何 bug**——对 `s["pos"]`（形状 `(L,3,3)`）用 `pos[i:i+4]` 切片，把残基块当成 4 个「点」喂给 `_cos_dih`，二面角 q 完全算错。**四个数现在收敛到一张表。**

## 四、查表的力：不过，而机制不是我以为的那个

**形状能对上。** `results/dihedral_nonharmonic_fit.log` 的 B2（测度修正的表）逐项误差 ≤ 0.02：

| 判据 | 参考 | B2 |
| :-- | --: | --: |
| cis 质量 | 63.2% | 61.2% |
| trans 质量 | 6.5% | 6.3% |
| trans 深度 | 2.25 kBT | 2.12 |
| 中间尾 | 30.3% | 32.5% |
| mean | 0.5956 | 0.581 |
| σ | 0.5920 | 0.588 |
| skew | −1.60 | −1.55 |

**力不过。** 收敛后的表（`results/force_reference.log`，chain-summed per-bead \|F\| = 积分器实际加帽的口径）：

| spec | 8 链 max | 2OIU max | 超帽 |
| :-- | --: | --: | --: |
| `shipped_harmonic` | 470 | 2479 | 0 |
| **`table`** | **5142** | **16478** | **2 / 3** |
| `exact_b2` | 5526 | 15736 | 3 / 3 |
| `reg eps=3°` | 5226 | 15736 | 2 / 3 |
| **`fourier N=2`** | **204** | **396** | **0** |
| `fourier N=4` | 225 | 598 | 0 |

> **注意 Fourier N=2 的最大力（396）比出厂的谐振子（2479）还小 6 倍。** 它分布拟合得更好的同时力更小。

### 机制：是几何发散，不是熵墙

**我一开始盯的是 `q→±1` 的熵墙，那是错的。** 日志里把两条并排量了出来：

```
window 46: q=0.999924, max|dq/dx| = 0.128 /nm   →  表力只有 134
          （q→1 附近几何因子反而衰减）

真正的 max 来自 2OIU 的 window 7（q = 0.0589）：
  三个 P-P 键近共线（|n0| = 0.0065, |n1| = 0.1626）
  →  max|dq/dx| = 187 /nm   ×   表斜率 70.4   →   13189
  bead 24（残基 8 的 P）再叠加 window 6 的 3319  →  16477
```

> **表格势最大的力来自「近共线键让 `dq/dx` 发散」，不是 `q→±1` 的熵墙。**

**而这条几何发散对任何 `q = cosφ` 参数化都存在**——Fourier 能压住，是因为它的势阱浅、`dV/dq` 小，**不是因为它没有这个发散**。所以「换个形式」并不能消除它；只有当 `dV/dq` 足够小、乘积留在帽内时才是安全的。

**两条精确的补充**（`scripts/reg_force_bound.py` → `results/reg_force_bound.log`）：

1. **`|dq/dx|` 在 `q→±1` 处不发散——它反而衰减**（合成几何上从 0.45 一路降到 0.0035）。所以极点那堵墙是 **`dV/dq` 在炸、几何良好**，而正则化地板确实压住了它（cis/trans 两侧对称，都按 `1−q²` 地板归零）。
2. **`|dq/dx|` 的发散与 `q` 无关**：三个 P-P 键近共线时法向量 `|n|→0`。所以 **`per-bead |F| = |dV/dq| × |dq/dx|` 里，压住前者并不压住后者**——这正是 `reg eps=3°` 在 2OIU 上给出与 `exact_b2` **一字不差**的 15735.80 的原因：真正的 max 在 `q=0.0589`，地板根本不触发。

> **这是 `q = cosφ` 这个参数化本身的几何性质，不是选哪个形式能消掉的。**

**样本里有真几何踩在 `q→1`**：8 条链 282 个窗口里 `|q|>0.99` 有 **41** 个、`|q|>0.999` 有 **13** 个；2OIU 68 个窗口里是 5 和 1。**所以那条边界不是理论上的。**

### 重分箱：救不了（保留）

| 表 | 2OIU max \|F\| | /cap |
| :-- | --: | --: |
| 现状网格（±1.04, 120），shipped | **16477** | **3.30** |
| [−1,1] 120 | **3190** | **0.64** |
| [−1,1] 240 | 17043 | 3.41 |

`[−1,1]`@120 字面上过关，但靠的是 coarsening（把 1000 个观测摊进整格、针抹成缓坡，最陡斜率还是从一个 6 观测的稀疏格捡来的）；**分得越细针越尖**。而按上面那个机制，**它压的根本不是真正的 max 来源**。

## 五、两个在这一周才暴露出来的问题

### 5.1 生产用的那张表**不可再生**

同一批 6386 个观测：

- shipped 表反推的计数是**小数**：bin117 = **1000.748**、bin118 = 0.179、bin116 = 592.103
- 现在的 `_table_from_values` 走**整数**直方图：1001 / 0 / 593
- **力：shipped 16477 vs 整数重拟合 7111——峰格上约 1 个观测的权重差把力摇了 2.3 倍**

来源追不到：`refit_tables_clean.py` 现在走 `B.fit()`，而 `_cgdata` **不是 git 仓库**，没有历史可查。

**这同时解释了「同一件事两个 agent 报出两个数」**——它们是**两张不同的表**，两个都对。

### 5.2 插值约定 gap，而它的免责理由已经被推翻

`scripts/boltzmann_bonded.py` 的 `_sample()` 把 bin **质量**当节点**值**读。它自己的 docstring 量过这个差：

```
angle     0.3624 kBT at the core   mass-weighted rms 0.034
dihedral  0.4925 kBT               mass-weighted rms 0.147
stack     0.2848 kBT               mass-weighted rms 0.027
```

而它写着「**不需要修**」，理由是：

> IBI is self-correcting for any convention … and **the shipped constants come from the spread (k = kBT/σ²), not from the table shape**.

**本周的发现把这个前提推翻了**：`k = kBT/σ²` 对这两条坐标**本来就是错的**（§1）。一旦表成为势，**表的形状就是势**，那 0.49 kBT 从「约定问题」变成「直接的势误差」。

C 的判断：**真正的人造物不是支撑范围，是这个约定 gap**——它把 cis 极小值钉在 0.9963 而不是 1.0，**让 `q→1` 附近的珠子吃一记反向的假力**。

## 六、修订后的候选：Fourier N=2

**力把「表格势更好」这个判断翻了过来。** 表格势在形状上更准（§4 的 B2 逐项 ≤0.02），但它的诚实 max 力是帽的 3.3 倍；Fourier N=2 在形状上代价是 **cis 峰钝 0.06**（0.576 对 0.632），而力 **max 396，余量 12 倍**。

| | 形状（逐项误差） | 力（2OIU max） | 可退化 |
| :-- | :-- | --: | :-- |
| **Fourier N=2**（K1=−2.78, K2=−1.33） | 见下表，**唯一大偏差是 cis 峰 −0.056** | **396** | 不干净（见下） |
| 表格 + 正则化 eps=3° | 逐项 ≤0.02 | 15736（**3.1× 帽**） | 干净（洗参考） |
| `exact_b2` | 逐项 ≤0.02 | 15736（**3.1× 帽**） | — |

**Fourier N=2 的六条判据整表**（`scripts/fourier_midtail_check.py` → `results/fourier_midtail_check.log`）：

| 判据 | 参考 | N=2 | 差 |
| :-- | --: | --: | --: |
| cis 位置 | 0.9967 | 0.9967 | 0 |
| **cis 质量** | 0.6317 | 0.5758 | **−0.056** |
| trans 位置 | −0.9967 | −0.9967 | 0 |
| trans 质量 | 0.0651 | 0.0710 | +0.006 |
| **中间尾（\|q\|<0.8）** | **0.3032** | **0.3532** | **+0.050** |
| trans 深度 | 2.25 | 2.22 | −0.03 |
| mean | 0.5956 | 0.5787 | −0.017 |
| σ | 0.5916 | 0.5902 | −0.001 |
| skew | −1.599 | −1.585 | +0.01 |
| mode | 0.9967 | 0.9967 | 0 |

**所以 N=2 的代价集中在一处**：cis 峰矮了 0.056，而缺的那点质量摊进了中间（+0.050）和 trans（+0.006）。**σ/skew/深度/中间尾全部对到 ≤0.01–0.05。**

### 「中间尾只给 10%」是拟合目标的定义问题，不是 N=2 的性质

这条曾经看起来是 Fourier 路线的致命伤，实际是**两种定义的差**。四个组合全测（N=4）：

```
correct 目标 + flat-φ 采样  →  mid = 0.3520     ← 正确口径
naive   目标 + flat-φ 采样  →  mid = 0.1077     ← 「10%」的来源
correct 目标 + flat-q 采样  →  mid = 0.6088
naive   目标 + flat-q 采样  →  mid = 0.3170
```

**`naive` = 拟合到 `U_ref` 而不含测度/Jacobian 项。** 丢 Jacobian 会让 cis 被过度堆积（0.81 对参考 0.63），**中间因此被抽空**——这和同一份工作里 `B1`（naive 表，mid 0.1212）对 `B2`（测度校正，mid 0.3246）是同一件事。

> **所以「低阶 Fourier 复现不了中间 30%」这句话，在正确口径下不成立。** 它复现了（0.353 对 0.303），只是稍多。

**退化开关**：
- 表格形式：**洗参考**（`q < −0.8` 的 bin 质量置零、重归一、重建表）——干净，按构造精确
- Fourier N=2：trans 井深度 = `−2·K1`，**K1 就是旋钮**；但洗参考后重拟合会留下残留 trans（N=2 时 0.101），**因为有限阶 Fourier 没有 `ln(sinφ)` 那堵墙，杀不净**

**所以这是一个取舍，不是碾压**：Fourier 力安全但退化带残留、cis 峰钝；表格精确但力超帽 3.3 倍。

### 力帽这一节因此只在选表格势时成立

`force_cap = 5000` 的存在理由是 README 那句「above every force observed on undamaged geometry, and below anything a numerical blow-up produces」。**表格势在无伤几何上就是 16478，那句话作废了**；而 **Fourier N=2 的 396 让那句话重新成立**。

| 只在选表格势时才要面对的选择 | 代价 |
| :-- | :-- |
| 抬帽 / 去帽 | 丢掉「帽是护栏不是力律」这条原则 |
| 保留帽、接受裁剪 | **按构造破坏 `F = −dE/dx`**——本周每一个测量都建立在那条上 |
| 重建表（更细 / 换插值） | §5.1、§5.2：shipped 表不可再生、插值 gap 未修；而且按 §4 的机制它压不到真正的 max 来源 |
| 正则化 | 对称性已核（`q=±0.999` 两侧同归零），但**压不住几何发散导致的 max** |

## 七、而这一切都是 E5 的前置

**IBI 的势最终要用换上去的那一项。** 而 E5（那个「输出分布」的采样环）**不只要写环**，它得先定：

1. **换 Fourier N=2 还是表格势**——上表那个取舍
2. **如果选表格**：用 shipped（不可再生）还是重拟合（力不同，差 2.3×）
3. **插值 gap 修不修**——`_sample` 的约定，其免责理由已被本周推翻
4. **`q→±1` 与近共线几何怎么处理**——按 §4，真正的 max 来源在这里

**这四条决定 IBI 迭代的那个势长什么样**，没有一条是纯实现细节。

## 八、还缺什么测量

1. ~~**Fourier N=2 的中间 30% 尾有没有被复现。**~~ —— **已做，且结论是「10%」为错**：那是拟合到 naive 目标（丢 Jacobian）的产物。正确口径下 N=2 给 0.3532 对参考 0.3032。见 §6。
